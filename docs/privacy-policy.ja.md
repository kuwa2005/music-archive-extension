# プライバシーポリシー

**楽曲制作アーカイブ**（Chrome 拡張機能）  
**最終更新:** 2026年6月9日  
**リポジトリ:** https://github.com/kuwa2005/music-archive-extension

本ポリシーは、本拡張機能が情報をどのように扱うかを説明します。Chrome ウェブストアおよび GitHub リポジトリからインストールしたビルドに適用されます。

## 概要

- **自動収集は行いません。** データは **ユーザーが保存操作を行ったときのみ**（ポップアップのボタン、コンテキストメニュー等）保存されます。操作なしにバックグラウンドで取得・アップロードすることはありません。
- **ローカル保存のみ。** 保存データはブラウザ内（IndexedDB および拡張機能のローカルストレージ）に留まり、**開発者のサーバーや第三者の分析サービスには送信されません。**
- **エクスポート・削除はユーザーが管理。** 検索ダッシュボードから JSON バックアップの出力やエントリの削除ができます。

## 拡張機能の目的

対応サイト（Suno および主要 AI チャット）上の楽曲制作関連コンテンツをローカルにアーカイブし、横断検索するためのツールです。**保存を依頼した時点**のページ内容（タイトル、歌詞、プロンプト等）を読み取り、端末内に保存します。

## ローカルに保存されるデータ

保存操作時に、次のような情報が保存される場合があります。

| データ | 用途 |
|--------|------|
| ページタイトル、歌詞、スタイル/プロンプト | 検索・アーカイブ |
| ソース URL、プラットフォーム（Suno / AI） | 元ページを開く、フィルタ |
| 日時（保存日時、Suno 生成日時が取得できた場合） | 並べ替え・表示 |
| ページ上に表示される AI 名等 | フィルタ・表示 |
| ユーザーが作成した AI と Suno の手動リンク | 横断参照 |
| 設定（自動リンク閾値、テーマ等） | 拡張機能の動作 |

自動リンク（保存済みエントリ間の歌詞・タイトル類似マッチ）は、**ユーザーが行った保存の後**にローカルで実行されます。外部送信はありません。

## 手動保存のみ

保存が行われるのは、次の場合 **のみ** です。

1. 拡張機能ポップアップの **「現在のページを保存」** をクリックしたとき  
2. **コンテキストメニュー**（「この Suno 曲を保存」「この AI 会話を保存」等）を使用したとき  
3. 以前エクスポートした JSON を **インポート** したとき（ユーザー自身のデータ）

ページ読み込み・遷移・DOM 変更による **自動保存はありません**。保存していない閲覧内容は記録されません。

## 保存場所

- **IndexedDB**（`MusicArchiveDB`）— アーカイブエントリとリンク  
- **`chrome.storage.local`** — 設定と UI 設定  

データは、削除・拡張機能のアンインストール・ブラウザデータの消去まで端末内に残ります。

## データの送信

アーカイブ内容を開発者や第三者のサーバーへ **送信して保存・分析することはありません**。

ネットワークアクセスは次に限定されます。

- **保存操作時** に、対応サイト上のコンテンツを読み取る（コンテンツスクリプト、および Suno メタデータ取得時の Suno 公開 API へのブラウザからのリクエスト）
- ダッシュボードから保存済み URL を開く際の通常のブラウザ通信

## エクスポート・インポート・削除

検索ダッシュボードの **設定 → データ管理** から:

- 全データの **JSON エクスポート**  
- **JSON インポート**（追加または置換。プロテクト指定エントリの保持あり）  
- 個別削除および条件指定の一括削除  

拡張機能のアンインストールや Chrome のデータ消去により、ローカルデータは Chrome の仕様に従って削除されます。

## 権限（用途）

| 権限 | 用途 |
|------|------|
| `storage` / `unlimitedStorage` | 設定とアーカイブ容量 |
| `activeTab` / `tabs` | アクティブタブからの保存、ダッシュボード表示 |
| `contextMenus` | ページ上メニューからの保存・ダッシュボード |
| `notifications` | ページ内ダイアログが使えない場合の保存/自動リンク通知 |
| ホスト権限（Suno、各 AI サイト） | **保存操作時のみ** コンテンツスクリプトでページを読み取る |

## 対応サイト

マニフェストに記載の Suno（`suno.com`）および主要 AI チャットサイト向けです。本拡張は Suno、OpenAI、Anthropic、Google、Microsoft、Perplexity、Poe 等の **公式製品ではなく、提携・後援もありません**。各サービスの利用規約に従ってご利用ください。

## 児童
