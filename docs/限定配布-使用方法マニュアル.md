# 限定配布版 — 使用方法マニュアル

**楽曲制作アーカイブ** の基本的な使い方です。  
インストールは **[限定配布-インストールマニュアル.md](./限定配布-インストールマニュアル.md)** を先に完了してください。

---

## 1. この拡張でできること

| 機能 | 説明 |
|------|------|
| **保存** | Suno の曲・リスト、AI チャットからタイトル・歌詞・プロンプト等を PC 内に保存 |
| **横断検索** | 歌詞の一部やタイトルから、過去に保存した Suno / AI データを検索 |
| **リンク** | AI で作った歌詞と Suno の曲を関連付け（自動 / 手動） |
| **バックアップ** | JSON でエクスポート / インポート |

**データの保存先:** お使いの Chrome 内のみ（IndexedDB）。クラウド同期はされません。

---

## 2. 対応サイト

### Suno

| ページ | 保存される主な内容 |
|--------|-------------------|
| 曲ページ（`/song/...`） | タイトル、歌詞、style プロンプト、URL |
| ワークスペース（`/create?wid=...`） | リスト内の曲 URL・タイトル・プロンプト |
| プレイリスト / マイページ等 | 曲 URL・タイトル・プロンプト |

### AI チャット

| サービス | ドメイン例 |
|----------|------------|
| ChatGPT | chatgpt.com / chat.openai.com |
| Claude | claude.ai |
| Gemini | gemini.google.com |
| Copilot | copilot.microsoft.com / copilot.com |
| Perplexity | perplexity.ai |
| Poe | poe.com |

## 3. 基本の流れ（はじめての方）

```
① Suno や AI で歌詞・曲を作る
        ↓
② 拡張でページを「保存」
        ↓
③ 検索ダッシュボードで歌詞の一部を検索
        ↓
④ 関連する AI 会話と Suno 曲がリンク付きで見つかる
```

## 4. データの保存方法

### 4.1 手動保存（確実・推奨）

1. 保存したい **Suno の曲ページ** または **AI チャット** を Chrome で開く
2. ツールバーの **楽曲制作アーカイブ** アイコンをクリック
3. **「現在のページを保存」** をクリック
4. 「保存しました」または「○ 件を保存しました」と表示されれば成功

**リストページ（プレイリスト・ワークスpace）** では、表示されている曲がまとめて保存されます。

### 4.2 右クリックメニュー

対象ページ上で **右クリック** すると、次のメニューが使えます。

| メニュー | 使えるページ |
|----------|--------------|
| この Suno 曲を保存 | Suno 曲ページ |
| このページの曲リストを保存 | Suno ワークスペース / プレイリスト等 |
| この AI 会話を保存 | 各 AI チャット |
| アーカイブを検索 | すべてのページ（検索画面を開く） |

### 4.3 自動保存（任意）

**初期設定では自動保存はすべて OFF** です。常に自動で取り込みたい場合のみ ON にしてください。

#### ポップアップから設定

拡張アイコン → 下部のチェックボックス:

- **Suno 自動保存** — 曲ページを開いたとき
- **AI チャット自動保存** — AI 会話ページを開いたとき
- **リスト自動保存** — ワークスペース / プレイリスト等

#### 検索ダッシュボードから設定

1. 検索ダッシュボード右上 **「設定」**
2. **「自動保存」** タブ
3. 必要な項目にチェック → **「保存」**

| 項目 | 動作 |
|------|------|
| Suno 曲ページを自動保存 | `/song/` ページを開くと保存 |
| AI チャットを自動保存 | 会話ページを開くと保存 |
| Suno リストを自動保存 | リスト系ページで曲 URL を検出すると保存 |

> 自動保存はページ内容の変更を監視します。意図しないタイミングで保存される場合は OFF に戻してください。

## 5. 検索ダッシュボード

### 開き方

- 拡張アイコン → **「検索ダッシュボード」**
- 右クリック → **「アーカイブを検索」**
- `chrome://extensions` → 楽曲制作アーカイブ → **「拡張機能のオプション」**

### 検索

1. 上部の検索ボックスに、**歌詞の一部・タイトル・AI 名・プロンプト** などを入力
2. 左の **検索結果** 一覧が絞り込まれます
3. 行をクリックすると右に **詳細** が表示されます

### フィルタ

| フィルタ | 説明 |
|----------|------|
| **すべてのソース** | Suno（曲 / ワークスペース / プレイリスト）や AI 別に絞り込み |
| **AI名 / GPT名フィルタ** | 特定の GPT 名・AI 名を含むものだけ |
| **リンク済みのみ** | 他のエントリと関連付け済みのものだけ表示 |

### 詳細画面

- **歌詞・メタ情報** の確認
- **関連 AI チャット** / **関連 Suno** — リンク済みエントリ一覧（クリックで元 URL を新しいタブで開く）
- **手動リンク** — ドロップダウンで AI と Suno を選び **「リンク作成」**
- **このエントリを削除** — 選択中のデータを削除

---

## 6. 自動リンク

保存時に、歌詞やタイトルの**類似度**が高い Suno 曲と AI チャットを自動で関連付けます。

### 設定（検索ダッシュボード → 設定 → 自動リンク）

| 項目 | 既定値 | 説明 |
|------|--------|------|
| **自動リンク閾値** | 0.75 | 高いほど厳しくマッチ（0.5〜1.0） |
| **リンク対象日数** | 30 | この日数以内に保存されたデータ同士だけ候補にする |

リンクが作成されると、Chrome の**通知**が表示されることがあります。

関連付けがうまくいかない場合は、詳細画面の **手動リンク** を使ってください。

---

## 7. バックアップ（エクスポート / インポート）

検索ダッシュボード右上 **「設定」** → **「データ管理」** タブから操作します。

### エクスポート

1. **設定** → **データ管理** タブ
2. **「エクスポート」** をクリック
3. JSON ファイルがダウンロードされます（保存データ・リンク情報を含む）

### インポート

1. **設定** → **データ管理** タブ
2. **「インポート」** をクリック
3. 以前エクスポートした JSON を選択
4. 既存データに**追加**されます（同名 ID は上書き）

**PC 移行・拡張再インストール前** にエクスポートしておくと安全です。

## 8. 典型的な使い方例

### 例 A: AI で歌詞 → Suno で作曲

1. ChatGPT 等で歌詞を作成 → AI ページで **「現在のページを保存」**
2. Suno で曲を生成 → 曲ページで **「現在のページを保存」**
3. 検索ダッシュボードで歌詞の一節（例: サビの最初の行）を検索
4. AI 会話と Suno 曲がリンクされていれば、詳細から両方の URL にジャンプ可能

### 例 B: ワークスペース内の曲をまとめて記録

1. Suno のワークスペース（`/create?wid=...`）を開く
2. リストが表示された状態で **「現在のページを保存」** またはリスト自動保存 ON
3. 検索ダッシュボードで曲タイトルやプロンプトを検索

### 例 C: 過去の制作物を歌詞から探す

1. 覚えているフレーズを検索ボックスに入力
2. ソースフィルタで **曲** または **ChatGPT** 等に絞る
3. 詳細から元ページへ

## 9. 注意事項

### データについて

- データは **その PC のその Chrome プロファイル内** にのみ存在します
- 拡張を削除するとデータも消えます
- 定期的な **エクスポート** を推奨します

### 動作の限界

- Suno / 各 AI の **Web サイトのデザイン変更** により、保存に失敗することがあります
- その場合はページを **再読み込み** してから手動保存を試してください
- 歌詞タブが別 UI の Suno ページでは、表示後に保存してください

### プライバシー

- 保存されるのは、**あなたが開いているページ上のテキスト**（歌詞、タイトル、URL 等）です
- 外部サーバーへの送信は行いません
- 自動保存を使う場合、意図しない会話テキストが含まれる可能性があります。不要なら **手動保存のみ** を推奨します

### 非公式ツール

本拡張は Suno / OpenAI / Anthropic / Google / Microsoft 等の**非公式**ツールです。各サービスの利用規約に従ってご利用ください。

## 10. よくある質問

### Q. 保存件数に上限はある？

理論上は数万件規模まで可能ですが、実用上は **500〜2,000 件程度** を目安に、古いデータの整理やエクスポートを検奨します。

### Q. 「リンク済みのみ」とは？

AI チャットと Suno 曲（またはその逆）が**関連付けされている**エントリだけを一覧に表示するフィルタです。

### Q. 自動保存 ON なのに保存されない

- 対応ページか確認（URL が Suno / 各 AI か）
- ページ読み込み完了後、数秒待ってから確認
- 設定ダッシュボードで自動保存が ON か再確認
- 手動保存で試す

### Q. Edge でも使える？

Chromium 系ブラウザ（Microsoft Edge 等）でも **デベロッパーモードでの読み込み** なら動作する可能性がありますが、**テストは Google Chrome 前提** です。

### Q. 不具合・要望はどこへ？

配布者が指定した連絡先、または GitHub リポジトリの Issues へ。
