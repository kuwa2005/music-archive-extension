# 限定配布版 — インストールマニュアル

**楽曲制作アーカイブ** Chrome 拡張（テスト版）を、Chrome Web Store 公開前に限られた方へ配布するための手順です。

> **対象:** Windows / macOS など、Google Chrome が使える環境  
> **配布形式:** ZIP を解凍したフォルダを、Chrome の「デベロッパーモード」で読み込む  
> **バージョン:** manifest `1.2.0` 時点

---

## 1. この拡張について（テスト版）

- Suno と主要 AI（ChatGPT / Claude / Gemini / Copilot / Perplexity / Poe）から、曲情報・歌詞などを**お使いの PC 内だけ**に保存します
- Chrome Web Store からのインストールではなく、**開発者モードでの sideload（側読み込み）** です
- データは外部サーバーへ送信されません（ブラウザ内に保存）

### テスト版であることの注意

| 項目 | 内容 |
|------|------|
| 配布範囲 | 配布者が許可した方のみ。ZIP の再配布はしないでください |
| 更新 | 新しい ZIP が届いたら、下記「更新手順」で差し替え |
| サポート | 不具合は配布者または GitHub Issues へ連絡 |
| 非公式 | Suno / 各 AI サービスの公式ツールではありません |

---

## 2. 事前準備

### 必要なもの

- **Google Chrome**（最新版推奨）
- 配布者から受け取った **ZIP ファイル**
- ディスク上に ZIP を解凍する場所（例: `D:\Apps\music-archive-extension`）

### 推奨環境

- Suno（https://suno.com）および利用する AI サービスに**ログインできる**こと
- 拡張がページ内容を読み取るため、対象サイトは通常どおりブラウザで開けること

---

## 3. ZIP の内容確認

解凍後、**次のファイル・フォルダがあること**を確認してください。

```
music-archive-extension/          ← このフォルダを Chrome に指定する
├── manifest.json                 ← 必須（ルートにあること）
├── dist/                         ← 必須（ビルド済み JS）
│   ├── service-worker.js
│   ├── suno-song.js
│   ├── suno-list.js
│   ├── ai-chat.js
│   ├── popup.js
│   └── dashboard.js
├── icons/
│   ├── icon16.png
│   ├── icon48.png
│   └── icon128.png
└── ui/
    ├── popup/
    └── dashboard/
```

### `dist` フォルダがない場合

配布 ZIP に `dist/` が含まれていない場合は、**Node.js がインストールされた PC** で次を実行してから Chrome へ読み込んでください。

```powershell
cd 解凍先\music-archive-extension
npm install
npm run icons
npm run build
```

`dist` フォルダが生成されたことを確認してから、手順 4 へ進みます。  
Node.js が無い場合は、配布者に **`dist` 入り ZIP** を再送してもらってください。

---

## 4. Chrome へのインストール手順

### 手順 1: 拡張機能ページを開く

Chrome のアドレスバーに次を入力して Enter:

```
chrome://extensions
```

### 手順 2: デベロッパーモードを ON

画面右上（または左メニュー）の **「デベロッパーモード」** をオンにします。

### 手順 3: 拡張機能を読み込む

1. **「パッケージ化されていない拡張機能を読み込む」** をクリック
2. ファイル選択ダイアログで、解凍した **`music-archive-extension` フォルダ** を選ぶ  
   （`manifest.json` が入っているフォルダそのものを指定。親フォルダや `ui` フォルダではない）
3. **「フォルダーの選択」** で確定

### 手順 4: 読み込み成功の確認

拡張機能一覧に **「楽曲制作アーカイブ」** が表示されれば成功です。

- エラーが出る場合 → [5. トラブルシューティング](#5-トラブルシューティング) を参照

### 手順 5: ツールバーにピン留め（推奨）

1. Chrome 右上の **パズルピースアイコン**（拡張機能）をクリック
2. **「楽曲制作アーカイブ」** の横の **ピン** をクリック
3. ツールバーからいつでも開けるようにします

---

## 5. インストール後の確認

1. ツールバーの拡張アイコンをクリック  
   → ポップアップに「保存件数: 0 件」などが表示されれば OK
2. ポップアップの **「検索ダッシュボード」** をクリック  
   → 検索画面が新しいタブで開けば OK
3. https://suno.com を開き、任意の曲ページで拡張アイコン → **「現在のページを保存」**  
   → 「保存しました」と出れば OK

詳しい使い方は **[限定配布-使用方法マニュアル.md](./限定配布-使用方法マニュアル.md)** を参照してください。

---

## 6. 更新手順（新しい ZIP が届いたとき）

1. `chrome://extensions` を開く
2. 既存の **「楽曲制作アーカイブ」** を **削除**（データも消えます。必要なら先にエクスポート）
3. 新 ZIP を**別フォルダ**に解凍するか、同フォルダを上書き
4. [4. Chrome へのインストール手順](#4-chrome-へのインストール手順) を再度実行
5. 拡張カードの **「更新」** ボタンだけでは ZIP 差し替えは反映されない場合があるため、**削除 → 再読み込み** が確実

### データを残したい場合

更新前に検索ダッシュボードの **「エクスポート」** で JSON を保存し、再インストール後に **「インポート」** してください。

---

## 7. アンインストール

1. `chrome://extensions` を開く
2. **「楽曲制作アーカイブ」** の **「削除」** をクリック

ブラウザ内に保存されたアーカイブデータも削除されます。

---

## 8. トラブルシューティング

### 「manifest.json が読み込めない」「拡張機能を読み込めません」

| 原因 | 対処 |
|------|------|
| フォルダ指定が間違っている | `manifest.json` があるフォルダを選び直す |
| `dist/` が無い | 上記「dist フォルダがない場合」を実行、または配布者に連絡 |
| ZIP の解凍が不完全 | 再解凍する |

### 「この拡張機能は、開発者モードで実行されています」と表示される

**正常な動作です。** Store 経由ではないため、Chrome が警告を表示します。テスト版では問題ありません。

### 拡張アイコンが灰色 / エラー表示

1. `chrome://extensions` で **「更新」** をクリック
2. 解凍フォルダを移動・削除していないか確認（**インストール後もフォルダは削除しない**）
3. Chrome を再起動

### 「取得に失敗しました。ページを再読み込みしてください」

1. 対象ページ（Suno 曲ページ、AI チャット等）を **再読み込み（F5）**
2. ページ表示後、もう一度 **「現在のページを保存」**
3. Suno / AI の UI 変更で一時的に失敗することがあります

### 保存しても件数が増えない

- 対応サイトか確認（Suno、ChatGPT、Claude 等。詳細は使用方法マニュアル）
- ポップアップの保存件数表示を開き直す

---

## 9. 配布者向けメモ（ZIP 作成）

テスターへ渡す ZIP には、**ビルド済み `dist/` を含める**ことを推奨します。

```powershell
cd music-archive-extension
npm install
npm run icons
npm run build
```

ZIP に含めるもの:

- `manifest.json`
- `dist/`（全体）
- `icons/`
- `ui/`

ZIP に**含めない**もの:

- `node_modules/`
- `src/`（任意。テスター向けなら省略可）
- `.git/`

使用方法マニュアル（本ファイルと `限定配布-使用方法マニュアル.md`）を同梱またはリンク共有してください。
