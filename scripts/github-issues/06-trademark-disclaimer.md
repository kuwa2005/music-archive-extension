## 概要

ストア説明・プライバシーポリシーに**商標・非公式免責**を追加する必要があります。

## リスク

- **低〜中** — 各社商標（ChatGPT / Claude / Gemini / Suno 等）使用時の誤認防止

## 推奨対策

- [ ] ストア説明に免責文を追加
- [ ] プライバシーポリシーにも同趣旨を記載

**文案例:**

> 本拡張は Google / OpenAI / Anthropic / Microsoft / Suno 等とは無関係の非公式ツールです。各名称は権利者の商標です。
