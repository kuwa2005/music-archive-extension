## 概要

Chrome Web Store 掲載用の**説明文・スクリーンショット等**が未準備です。

## リスク

- **中** — 提出自体が完了しない、または掲載品質が低くなる

## チェックリスト

- [ ] ストア説明文（日本語、必要なら英語）
- [ ] スクリーンショット 1 枚以上（1280×800 または 640×400）
- [ ] 小アイコン 128×128（manifest と整合）
- [ ] （推奨）プロモーション用タイル 440×280
- [ ] カテゴリ選定（例: Productivity）
- [ ] プライバシーポリシー URL（#1 と連動）
- [ ] 権限 justification 各項目（#4 と連動）

## 推奨スクリーンショット内容

- 検索ダッシュボード
- 詳細・リンク画面
- 設定（自動保存 OFF 既定の表示）
